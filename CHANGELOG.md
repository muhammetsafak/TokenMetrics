## [0.1.0] - 2026-11-08

### Added

- Usage collection from Claude Code, Codex CLI and Gemini CLI logs, and from the
  Anthropic and OpenAI Admin APIs.
- Overview with totals, a token chart, a subscription limits card and a model
  comparison table; comparison, project, limits, data and settings screens.
- Estimated costs from an editable price table, and estimated 5-hour and weekly
  subscription limit tracking.
- Budget alerts as OS notifications and as an alert state of the tray icon.
- System tray icon; on macOS a template icon that follows the menu bar
  appearance.
- Manual entry, CSV import, and JSON and CSV export.
- Admin API keys stored in the OS keychain.
